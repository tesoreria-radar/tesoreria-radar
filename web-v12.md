# V12 — Modelo 100% Web

## Experiencia
- Acceso por navegador, desktop o móvil.
- No requiere instalación.
- Dashboard con navegación por módulos.
- Estado del sistema visible.
- Actualización automática cada 5 minutos.
- PWA manifest para experiencia web instalada opcionalmente.

## Principio
El navegador es sólo la interfaz. Fuentes, secretos, IA, persistencia, scheduler y credenciales viven en backend.

## Módulos
Resumen / Alertas / Mercado / ARCA / Cash Calendar / BCRA / Real Estate / Vaca Muerta.

## Producción
Para completar la puesta en producción faltan únicamente las credenciales/provisionamiento de infraestructura y los adaptadores de fuentes reales. La interfaz no depende de una instalación local del usuario.
